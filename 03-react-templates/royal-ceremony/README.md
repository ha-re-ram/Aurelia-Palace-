# Aurelia Palace — Royal Ceremony Edition

A luxury immersive resort web application template crafted with **React, Vite, and Tailwind CSS**.

## ✨ Features

- **Interactive Opening Ceremony**: Cinematic entrance curtains and crest animation that introduces guests to the palace.
- **Dynamic Gold Dust Effect**: Ambient canvas particles floating across the interface.
- **Custom Cursor & Ornaments**: Bespoke gold luxury cursor with trailing effects and heritage ornamental dividers.
- **Comprehensive Sections**:
  - `Hero` — Grand palace entrance banner with scroll trigger.
  - `Journey` — Curated royal experiences and historical timeline.
  - `Heritage` — Architectural grandeur and royal pedigree.
  - `Chambers` — Luxury suites with pricing, sizing, and amenities.
  - `Dining` — Fine dining, Michelin-starred culinary venues.
  - `Gardens & Grounds` — Serene landscaped lawns and royal courtyards.
  - `Spa & Wellness` — Ayurvedic therapies and wellness retreats.
  - `Guestbook` — Verified royal reviews and visitor impressions.
  - `Reserve` — Direct suite booking & inquiry form.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## 🛠️ Tech Stack
- **Framework**: React 18
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Utilities**: `clsx`, `tailwind-merge`
