# Aurelia Palace — Heritage Palace Edition

A refined luxury hotel and destination resort template with quick booking actions, modular site configuration, and mobile-optimized docks.

## ✨ Features

- **Opening Ceremony & Reveal**: Elegant welcoming transition into the palace portal.
- **Fact Strip**: Key luxury metrics (acres, suites, banqueting capacity, heritage legacy) in high-impact typography.
- **Modular Data Source**: Centralized `src/data/site.ts` configuration for phone numbers, emails, addresses, suite details, and amenities.
- **Mobile Floating Action Dock**: One-tap Call, Email, and Reserve bottom navigation optimized for smartphone users.
- **Full Showcase Sections**:
  - `Hero` with royal crest and interactive reveal.
  - `FactStrip` with quick key statistics.
  - `Journey` & `Heritage` historical narrative.
  - `Chambers` suite catalog.
  - `Celebrations` for grand royal weddings and banquets.
  - `Grounds` & `Arrival` concierge and spa services.
  - `Reserve` suite booking drawer.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## 🛠️ Customization
Update hotel phone numbers, emails, room details, and social links in:
```
src/data/site.ts
```
