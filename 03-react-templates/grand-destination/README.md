# Aurelia Palace — Grand Destination & Celebrations Edition

A luxury wedding resort, banquet, and hotel destination web application built with **React, Vite, Tailwind CSS, and Framer Motion**.

## ✨ Features

- **Interactive Intro Curtain**: Cinematic entry screen with smooth dismissal.
- **Scroll Spring Progress Bar**: Ultra-responsive golden gradient reading/scroll indicator at the top of the viewport.
- **Ambient Cursor Glow**: Dynamic gold atmospheric light following pointer movement on desktop.
- **Rich Motion Components**:
  - `Hero` with animated typography and dynamic CTA triggers.
  - `Welcome` overview highlighting estate heritage.
  - `Rooms` interactive suite showcase with image transitions.
  - `Celebrations` dedicated wedding and gala event planning section.
  - `Gallery` interactive media grid with lightbox and category filtering.
  - `Amenities` comprehensive resort facilities (Infinity Pool, Wellness Spa, Fine Dining, Heli-pad).
  - `Testimonials` guest reviews and media citations.
  - `Faq` accordion for wedding bookings, check-in, and guest policies.
  - `Contact` rich inquiry form with validation and location details.
  - `MobileBar` fixed bottom navigation bar for mobile visitors.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## 🛠️ Tech Stack
- **Framework**: React 18
- **Animation**: Framer Motion
- **Styling**: Tailwind CSS
- **Bundler**: Vite
