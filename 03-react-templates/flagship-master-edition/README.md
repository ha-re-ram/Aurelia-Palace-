# 👑 Aurelia Palace — Official Master Flagship Edition

The ultimate, comprehensive web application built for Aurelia Palace. This edition harmonizes the finest interactive components from all previous templates into a unified, high-performance **React 19 + Framer Motion** luxury digital experience.

## 🌟 Highlights & Combined Features

- **Royal Opening Ceremony**: Cinematic entrance curtains parting with royal crest and skip toggle.
- **Scroll Spring Progress Bar**: Golden gradient progress line responding with physical spring dynamics.
- **Ambient Pointer Glow & Luxury Cursor**: Custom gold cursor ring with ambient atmospheric light follower.
- **Fact Strip / Key Metrics**: 62+ Air-Conditioned Suites, 30,000 sq. ft. celebration lawns, 12,000 sq. ft. ballroom, 50-year legacy.
- **Interactive Suite Showcase**: Dynamic tabbed chamber selector with pricing, square footage, amenities, and direct reservation triggers.
- **Weddings & Celebrations Section**: Comprehensive event planner for multi-day royal weddings, receptions, and sangeet ceremonies.
- **Culinary Artistry & Dining**: Dedicated showcase of fine dining restaurants with separate vegetarian and multi-cuisine kitchens.
- **Filterable Media Gallery**: Interactive gallery with category filtering and full-screen lightbox modal.
- **Resort Amenities**: 8-point luxury amenities grid with hover micro-animations.
- **Guestbook & Verified Reviews**: Real guest impressions and five-star rating highlights.
- **Interactive FAQ Accordion**: Instant answers to common booking, wedding, and check-in queries.
- **Direct Suite Booking Modal**: Reservation drawer with check-in/out dates, guest selector, suite dropdown, and direct WhatsApp integration.
- **Event & Banquet Inquiry Modal**: Dedicated wedding and gala event planning form with WhatsApp pre-fill.
- **Mobile Floating Action Dock**: Quick-action buttons for Call, WhatsApp, and Reserve on smartphones.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production (Single-file Zero-dependency Static Bundle)
```bash
npm run build
```
The output will be generated in `dist/index.html`—a single, optimized production file ready for instant deployment anywhere.
