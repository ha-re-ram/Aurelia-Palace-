# Aurelia Palace — React & TypeScript Templates Collection

This directory contains five distinct, production-ready React + Vite application templates built for Aurelia Palace. Each template represents a different architectural style, feature set, and visual mood.

## 📊 Template Comparison Matrix

| Template | Tech Stack | Key Architectural Features | Best For |
|---|---|---|---|
| **`flagship-master-edition/`** | React 19, Vite, Tailwind CSS, Framer Motion | Opening ceremony curtain, scroll spring bar, ambient pointer glow, suite selector, wedding planner, fine dining, booking & event modals, mobile dock | Official full-featured commercial resort & wedding destination deployment |
| **`grand-destination/`** | React 19, Vite, Tailwind CSS, Framer Motion | Smooth scroll spring progress, ambient glow cursor, rooms gallery, FAQ accordion, wedding celebrations | Grand palace hotels, luxury wedding destinations, event convention venues |
| **`royal-ceremony/`** | React 19, Vite, Tailwind CSS, Custom Canvas | Opening ceremony curtain, gold dust canvas particles, custom luxury cursor, guestbook | Immersive luxury storytelling, high-end boutique resorts, heritage villas |
| **`heritage-palace/`** | React 19, Vite, Tailwind CSS, Central Data Config | Centralized `site.ts` data store, fact strip statistics, mobile reservation dock, rapid booking | Commercial hospitality deployments requiring easy content editing and mobile conversion |
| **`resort-experience/`** | React, Vite, Tailwind, Modular Components | Modular sections, amenities grid, event inquiry dialog, room cards | Modern full-featured hotel web applications |

## 🚀 Quickstart for Any Template

Navigate into any template directory:
```bash
cd flagship-master-edition   # or grand-destination, royal-ceremony, etc.
npm install
npm run dev
```
Open `http://localhost:5173` (or the port specified in terminal) to view the live template.
