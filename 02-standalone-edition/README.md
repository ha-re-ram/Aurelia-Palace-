# Aurelia Palace — Standalone Interactive Luxury Edition

A zero-dependency, ultra-high-performance single-page luxury hotel website.

## 🌟 Highlights

- **Zero Runtime Dependencies**: No npm packages, no heavy frameworks, no build step required. Just open `index.html` directly in any web browser.
- **Audited Animation Token System**: Includes verified motion design tokens, stagger delays, ripple transitions, and scroll reveals documented in `ANIMATION-AUDIT.md` and `ANIMATION-IMPLEMENTATION.md`.
- **Authentic Client Photography**: Includes original hotel imagery (`assets/client-photos/`), vector emblems, and luxury brand marks.
- **Full Interactive Suite**:
  - Parallax hero and smooth reveal animations.
  - Interactive suite reservation modal.
  - Dining & banquet event showcase.
  - Interactive gallery grid with stagger animation.
  - Direct WhatsApp, telephone, and map integrations.

## 🚀 How to Run

### Direct Open
Double-click `index.html` in your file explorer, or open it directly in Chrome, Edge, Safari, or Firefox.

### Local HTTP Server (Optional)
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
