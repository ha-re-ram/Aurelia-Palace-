# Aurelia Palace — Conceptual Prototypes & Design Explorations

This directory preserves early conceptual prototypes, stylistic variations, and layout explorations developed during the evolution of the Aurelia Palace template suite.

## 📁 Prototype Breakdown

| Folder | Layout Style | Tech Stack | Notes |
|---|---|---|---|
| `01-classic-heritage/` | Classic Gold Heritage | Vanilla HTML5, CSS3, JS | Multi-section layout with luxury estate imagery, 2,298 lines of code, and 80:20 gold-white balance. |
| `02-minimal-editorial/` | Minimal Editorial | Single-file HTML | Fast conceptual single-file luxury layout with clean typography. |
| `03-modern-aesthetic/` | Modern Luxury Serif | Single-file HTML | Modern luxury hotel concept with responsive sections. |
| `04-symmetrical-regal/` | Symmetrical Regal Architecture | Single-file HTML | Symmetrical royal layout with luxury borders and smooth scrolling. |
| `05-archival-drafts/` | Historical Early Drafts | HTML | Historical drafts (`V1 Aurelia Palace.html` and `V2 Aurelia Palace.html`) showing earlier iterations of the standalone site. |

## 🚀 How to View Any Prototype

Each folder contains self-contained HTML files. Simply open the corresponding `index.html` (or `aurelia-palace.html`) in any modern web browser or run:
```bash
python3 serve.py
```
